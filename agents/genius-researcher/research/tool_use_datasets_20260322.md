# Tool-Use Datasets on HuggingFace — Research Report

## Tier 1: Top Recommendations (Multi-Turn, Production-Quality)

### 1. NVIDIA Nemotron-Agentic-v1
- **HF:** [nvidia/Nemotron-Agentic-v1](https://huggingface.co/datasets/nvidia/Nemotron-Agentic-v1)
- **Size:** 181K samples
- **Format:** JSONL, multi-turn conversations
- **License:** CC BY 4.0
- **Why:** Best all-in-one dataset. Synthetic multi-turn trajectories — models decompose goals, decide when to call tools, reason over outputs. Generated using Qwen3-235B with turn-level quality judgments.
- **Issues:** Synthetic only, very new (2025)

### 2. Salesforce APIGen-MT-5k
- **HF:** [Salesforce/APIGen-MT-5k](https://huggingface.co/datasets/Salesforce/APIGen-MT-5k)
- **Size:** 5K multi-turn trajectories
- **Format:** ShareGPT
- **License:** CC BY 4.0
- **Why:** Purpose-built for multi-turn agentic tool use. Models trained on this outperform GPT-4o and Claude 3.5 on tau-bench and BFCL. NeurIPS-accepted paper.
- **Issues:** Only 5K public (full xLAM-2 training set is larger but private)

### 3. interstellarninja/hermes_reasoning_tool_use
- **HF:** [interstellarninja/hermes_reasoning_tool_use](https://huggingface.co/datasets/interstellarninja/hermes_reasoning_tool_use)
- **Size:** 51K examples (~392 MB)
- **Format:** ShareGPT (Hermes format), axolotl-compatible
- **Why:** Large-scale multi-turn tool calling WITH chain-of-thought reasoning. Built with Nous Research Atropos RL stack. Aligned with BFCL v3 evaluation.
- **Issues:** Community-built, quality may vary

### 4. FunReason-MT
- **HF:** [Bingguang/FunReason-MT](https://huggingface.co/datasets/Bingguang/FunReason-MT)
- **Size:** 16K multi-turn samples
- **Format:** Chat/conversation
- **Why:** Addresses "complexity barrier" in multi-turn function calling. 4B model trained on this achieves SOTA on BFCL v3 among comparable-sized models.
- **Issues:** Relatively new, smaller community

## Tier 2: Strong Single-Turn + Some Multi-Turn

### 5. Salesforce/xlam-function-calling-60k
- **HF:** [Salesforce/xlam-function-calling-60k](https://huggingface.co/datasets/Salesforce/xlam-function-calling-60k)
- **Size:** 60K examples
- **License:** CC BY 4.0
- **Why:** The OG function calling dataset. 21 domains, 3,673 APIs. 328+ models trained on it. Has official fine-tuning cookbook.
- **Issues:** Primarily single-turn

### 6. ToolBench (ToolLLM)
- **HF:** [tuandunghcmut/toolbench-v1](https://huggingface.co/datasets/tuandunghcmut/toolbench-v1)
- **Size:** 188K training rows
- **License:** Apache 2.0
- **Why:** Massive scale. 16,464 real-world RESTful APIs. ICLR 2024 spotlight.
- **Issues:** APIs may be stale. Generated by GPT-3.5-turbo-16k.

### 7. ToolACE
- **HF:** [Team-ACE/ToolACE](https://huggingface.co/datasets/Team-ACE/ToolACE)
- **Size:** 11.3K rows
- **License:** Apache 2.0
- **Why:** Self-evolution synthesis pipeline. 26,507 APIs. Multi-agent interplay generation.

### 8. NousResearch/hermes-function-calling-v1
- **HF:** [NousResearch/hermes-function-calling-v1](https://huggingface.co/datasets/NousResearch/hermes-function-calling-v1)
- **Size:** ~12K samples
- **License:** Apache 2.0
- **Why:** Powers Hermes 2 Pro. Single + multi-turn, JSON-mode, agentic JSON-mode.
- **Issues:** Small

### 9. Glaive Function Calling v2
- **HF:** [glaiveai/glaive-function-calling-v2](https://huggingface.co/datasets/glaiveai/glaive-function-calling-v2)
- **Size:** 113K rows
- **Why:** Large scale, widely used. Many community reformats.
- **Issues:** Older, lower quality than newer datasets

## Tier 3: Specialized — Tool Composition & Agentic Workflows

### 10. CapitalOne/T1 (Tool Composition)
- **HF:** [capitalone/T1](https://huggingface.co/datasets/capitalone/T1)
- **Size:** 13.5K dialogues
- **Why:** Specifically designed for inter-tool dependencies. 9 domains. Outputs of one tool feed into another. Best for training tool coordination.
- **Issues:** Domain-limited to travel/booking

### 11. TaskCraft (Difficulty-Scalable)
- **HF:** [PersonalAILab/TaskCraft](https://huggingface.co/datasets/PersonalAILab/TaskCraft)
- **Size:** ~36-41K tasks
- **Why:** Depth/width extensions create hierarchically complex challenges. Great for tool composition and multi-step planning. Includes sub-task decomposition data.

### 12. CoALM / CALM-IT
- **HF:** [vipulgupta/CALM](https://huggingface.co/datasets/vipulgupta/CALM)
- **Why:** Unifies Task-Oriented Dialogue + Language Agent. Outperforms GPT-4o on MultiWOZ 2.4, BFCL V3.

## Gap: Tool Creation

No dedicated dataset found for tool creation (agents defining new tool schemas and implementations). This is still a gap in the open-source ecosystem.

## Recommended Training Recipe

1. **Nemotron-Agentic-v1** (181K) — backbone for multi-turn agentic tool use
2. **hermes_reasoning_tool_use** (51K) — adds chain-of-thought reasoning
3. **xlam-function-calling-60k** (60K) — broadens single-turn coverage
4. **APIGen-MT-5k** (5K) — high-quality multi-turn with verified ground truth
5. **FunReason-MT** (16K) — complex multi-turn scenarios

For **tool composition**: add T1 (13.5K) + TaskCraft (36K)
