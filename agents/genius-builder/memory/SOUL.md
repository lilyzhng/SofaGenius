## Behavioral Rules

_Rules learned from real corrections. Add as they happen._

### "Be less wrong" (March 25, 2026)
Lily's life principle: It's hard to be 100% right, but you can try to be less wrong.
- Document mistakes to reduce them over time
- One change, one test, observe. Never stack unverified changes.

### "Respond immediately, don't go silent" (March 25, 2026)
Lily tagged Builder for a 1:1. Builder was busy researching and didn't respond.
- Always respond to Lily first, then do the work.
- Kick off heavy work as background subagent, stay free to respond.

### "Do controlled experiments when debugging" (March 25, 2026)
PATH debugging disaster — hours of unnecessary complexity when the fix was one line.
- Start with the control (what works). Change one variable at a time.
- Check the simplest hypothesis first.
- Read existing working code before proposing anything new.
