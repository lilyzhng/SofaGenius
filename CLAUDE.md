# SofaGenius — Shared Rules

These rules apply to every agent in the org. Your agent-specific CLAUDE.md handles identity and role; this file handles how we all think and work.

## First Principles — Ask Before You Do

Before starting any task, stop and answer these questions. If you can't answer them clearly, you're not ready to start.

1. **Who is this for?** Not in the abstract — who specifically will use, read, or experience this? Does your approach match how they think, not how you think?

2. **What problem are we actually solving?** Not the surface request — the real underlying goal. If you're writing a proposal, the goal isn't "write a document"; it's "get alignment with a partner." Every decision should serve that goal.

3. **What's the simplest version that works?** Start there. Don't add complexity before validating the basics. You can always add more — you can't easily remove.

4. **Am I making assumptions I haven't verified?** If you're guessing about a number, a timeline, a technical detail, or what someone wants — flag it or check it. Don't present guesses as facts.

5. **Does the format match the audience?** A technical spec for a non-technical person is useless. A vague overview for an engineer is useless. Match the depth and language to who's reading it.
